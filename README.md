# Unity Mobile VFX Particles

**A small Unity URP sandbox for experimenting with Visual Effect Graph particles** on a mobile-oriented render pipeline setup.

---

## Status

Very early experiment. Almost no authored gameplay code — the meaningful content is VFX Graph assets on top of a Unity URP template.

## Tech stack

| Area | What it uses |
|---|---|
| Engine | **Unity 2022.3.46f1**, **URP** |
| VFX | **Visual Effect Graph** (`.vfx` assets) |

## What's in the project

| Content | Path |
|---|---|
| Sample VFX graphs | `Assets/VFX/MyEffect.vfx`, `Assets/VFX/MyEffect 1.vfx` |
| URP quality presets | `Assets/Settings/` |
| Template readme scripts | `Assets/TutorialInfo/Scripts/` |

## About this repository

Portfolio note: this repo is a VFX sandbox, not a gameplay systems sample. Prefer the networked / procedural repositories for programming evidence.
